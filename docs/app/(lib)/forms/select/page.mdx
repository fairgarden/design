# Select

One choice from a known list of about 5–15 options: Base UI's Select, inside a `Field`. For 2–4 options that should stay visible use Radio or Toggle Group; for long or searchable lists use Combobox.

```tsx
import { Select } from '@fairgarden/design/forms/select'
```

Pass `items` (options, or titled groups) and a `placeholder` that ends in "…". Label the trigger with `<FieldLabel nativeLabel={false}>`, which focuses it without opening the popup. The popup opens `--size-px-2` below the trigger, never on hover and never as a sheet; at most 8 items show before it scrolls. For custom rows, pass `SelectItem`, `SelectGroup` and `SelectSeparator` as children.

## Variants and states

import { DemoSelectStates } from './demos/states'

<DemoSelectStates.Title />

The boxed trigger is the field box; `variant="underline"` sets the trigger over a `--border-size-2` `--role-accent` underline that hugs its content. Highlighted items take the `--primary4` soft fill and a `--border-size-2-25` start bar; the chosen item a leading ✓ and `--font-weight-6`; a disabled item stays muted and is never highlighted. An option with a `swatch` draws the product's color before its name.

## Outline morph

import { DemoSelectMorph } from './demos/morph'

<DemoSelectMorph.Title />

On by default: as the popup opens, the trigger's focus ring grows into the popup's `--border-size-2` `--primary12` frame, and the list is revealed inside it; on close the frame shrinks back onto the ring. Opened by pointer, where no ring shows, the field edge grows instead. The trigger's own styles are unchanged: the growing frame is an overlay, and it gives way to the popup's own frame the moment it lands. It opens over `--fgd-duration-expand` on `--fgd-ease-expand` and closes over `--fgd-duration-disclosure`; under reduced motion it is instant, and in forced colors and print the popup opens as usual. `morph={false}` opens and closes the popup at once; see [Outline Morph](../../foundations/outline-morph/page.mdx) for the app-wide switch. The last select sits at the foot of a tall stage: with the demo near the top of the window it opens upward, and the outline grows up.
