## API Reference

### ExpandingBox

A 9-slice frame in three rows (head, content, foot), rendered as direct
children of the host (give that element `expandingBoxParts.host`). Each
row carries the scope attributes and the scale classes. While `active`,
its pieces carry View Transition names, so the owner's
`startExpandingTransition` morphs this box into the pair's other box:
corners translate, edges stretch, main rides the left edge, `end` the
right, and the extra grows.

### ExpandingBoxExtra

The extra piece (dialog: the results). If omitted, the box renders an
empty one, so the trigger's empty extra grows into the dialog's.

### ExpandingBoxMain

The main piece (trigger: icon, label and shortcut hint; dialog: the input
row). Rides the left edge. Renders the box's `as`.

### startExpandingTransition

Runs `update` (the state change that swaps which box is active) as the
morph. Resolves once the morph finishes, or on a microtask when it doesn't
run. Never rejects.

Without View Transitions, without `view-transition-class`, or under
`prefers-reduced-motion: reduce` (read at call time), it calls `update()`
directly; the owner's own fallback applies then (the Dialog's clip reveal
where motion is allowed, else instant). Otherwise it sets
`<html data-fgd-expanding="open|close">` and calls
`document.startViewTransition(() => flushSync(update))`, removing the flag
when the last running morph settles. Re-entry guards are the owner's.

| Parameter | Type                              | Default | Description |
| :-------- | :-------------------------------- | :------ | :---------- |

| options   | `StartExpandingTransitionOptions` | -       | -           |

### useExpandingBoxName

A pair name from `useId()`, sanitized to a custom-ident: `fgd-xb-<id>` with
`[^A-Za-z0-9_-]` replaced by `-`. Call it once in the owner and pass it to
both boxes of the pair.

**useExpandingBoxName Return Value:**

```tsx
type ReturnValue = string;
```

### ExpandingTransitionDirection

Which way the morph runs: `open` grows the trigger into the dialog; `close` is the faster way back.

```typescript
type ExpandingTransitionDirection = 'open' | 'close';
```

### StartExpandingTransitionOptions

Options for `startExpandingTransition`.

```typescript
type StartExpandingTransitionOptions = {
  /** `open` or `close`: sets `<html data-fgd-expanding>`, which picks the timing. */
  direction: ExpandingTransitionDirection;
};
```
