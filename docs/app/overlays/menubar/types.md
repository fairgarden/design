## API Reference

### Menubar

The bar (Base UI Menubar): --ds-size-hit tall with a --border-size-1
\--role-rule under it, holding `MenubarMenu`s. Below --lg-n-above it
collapses into one `collapsedLabel` trigger whose popup lists each menu
as a labelled group.

### MenubarMenu

One menu of the bar: a `type-button-sm` trigger and a Menu popup of its
items. Inside the collapsed "Menu" it renders as a MenuGroup under a
MenuGroupLabel of the same label.

**MenubarMenu Props:**

| Prop       | Type              | Default | Description                                                                                                                                      |
| :--------- | :---------------- | :------ | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| label      | `string`          | -       | The trigger's label, authored in title case with no tracking ("File",&#xA;"Edit", "View Options") \[D160, D165]; the group label when collapsed. |
| popupProps | `MenuPopupProps`  | -       | Props for the menu's popup (placement, color axes).                                                                                              |
| disabled   | `boolean`         | -       | Disables the trigger.                                                                                                                            |
| children   | `React.ReactNode` | -       | The menu's items: MenuItem, MenuCheckboxItem, MenuRadioGroup, MenuSubmenu …                                                                      |
