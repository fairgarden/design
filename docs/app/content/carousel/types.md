## API Reference

### Carousel

The carousel. Swipe, trackpad, the Previous and Next buttons, and the
arrow, Home and End keys on the focused track all move it one slide at a
time with snap. In print, card slides become a 2-up grid and photo sets
of up to 6 a 3-up grid; a larger photo set prints its first slide and
"n more images (short URL)".

### CarouselPhoto

A photo slide: a §8.5 photo Figure with the image at its own ratio and
the caption right-flush under it.

**CarouselPhoto Props:**

| Prop     | Type                                                                                                         | Default | Description                                                                 |
| :------- | :----------------------------------------------------------------------------------------------------------- | :------ | :-------------------------------------------------------------------------- |
| alt\*    | `string`                                                                                                     | -       | The alternative text; empty only for a decorative photo.                    |
| caption  | `React.ReactNode`                                                                                            | -       | The caption: what to notice. Always visible, right-flush.                   |
| credit   | `React.ReactNode`                                                                                            | -       | The credit, in the same run: "Photo: Name / Program".                       |
| imgProps | `Omit<React.DetailedHTMLProps<React.ImgHTMLAttributes<HTMLImageElement>, HTMLImageElement>, 'src' \| 'alt'>` | -       | Image `srcSet`, `sizes`, `loading` and other attributes.                    |
| ratio\*  | `number`                                                                                                     | -       | The photo's own width ÷ height (e.g. `3 / 2`), so the strip never crops it. |
| src\*    | `string`                                                                                                     | -       | The image source.                                                           |

### CarouselSlide

One slide, labelled "n of N" for assistive technology. It snaps to its
start; slides are focusable only through their own links.

**CarouselSlide Props:**

| Prop  | Type     | Default | Description                                                                                                                                                                     |
| :---- | :------- | :------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ratio | `number` | -       | The photo's width ÷ height (e.g. `3 / 2`). From 1024 px of container&#xA;the photo strip sizes the slide from it at the 480 px track height, so&#xA;nothing is cropped \[D186]. |
