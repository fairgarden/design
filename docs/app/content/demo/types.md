## API Reference

### DemoContent

A demo: the live component on the page ground, with a Select of the
variants in its top-start corner (two or more), above the embedded code
with the file tabs, the actions (copy, copy link, view source, TS | JS)
and, with `collapse`, the window. Every file's `#slug` has a hidden
scroll target before the frame.

### DemoLazy

Demo, code-split: the demo factories' `DemoContent` that loads
DemoContent (`useDemo`, the code section, the Select) in its own chunk,
as fg-docs' DemoContentLazy. Pair it with `DemoContentLoading:
DemoLoading`, which shows while the chunk loads. Props, `renderPreview`
included, pass through to DemoContent.

````typescript

   * Collapses the code to its window (`@focus`, emphasis) with the "Show all {n} lines" toggle,
